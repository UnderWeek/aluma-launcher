# Aluma Launcher icon

The current mark is an original flat cube-comet: three cube faces and two square
particles on a transparent background. Mint, teal, and periwinkle are solid
fills. There are no fonts, textures, gradients, shadows, or Minecraft assets.

- `aluma-icon.svg`: editable source and interface/favicon asset.
- `aluma-icon.png`: 1024 px transparent export.
- `aluma-icon-512.png`: Electron window/Dock asset.
- `aluma-icon.icns`: macOS icon bundle for future packaging.

The SVG replaces the earlier generated A monogram. Raster exports are rendered
from the SVG; change the SVG first when updating the mark.
