# Aluma Launcher

[English](README.md) · Русский

Независимый лаунчер Minecraft: Java Edition на Electron и обычном JavaScript.
Aluma позволяет создавать отдельные сборки, использовать Vanilla и Fabric,
искать моды и входить через аккаунт Microsoft.

**Статус:** в разработке. Готовые установочные пакеты пока недоступны.
Вход Microsoft реализован, но для доступа приложения к Minecraft Services API
ещё требуется одобрение; сейчас вход в игровой аккаунт получает HTTP 403.

## Запуск локально

```sh
npm ci
npm start
```

## Пользовательские данные

Настройки, аккаунты, версии игры, библиотеки, Java и данные Electron хранятся
в домашней папке пользователя:

- macOS/Linux: `~/.aluma/`
- Windows: `%USERPROFILE%\.aluma\`
- Сборки: `.aluma/instances/<название>/minecraft/`

При первом переносе существующая папка `data/` из репозитория копируется в
`.aluma`, если новый каталог ещё не существует. Старая папка остаётся резервной
копией. В настройках можно выбрать другой каталог для сборок.

## Установка модов

В каталоге выберите сборку Fabric, включите переключатели нужных модов и нажмите
**«Скачать выбранное»**. Выбор сохраняется при поиске и загрузке следующих страниц.

Для Modrinth лаунчер собирает обязательные зависимости, учитывает точные ID версий
и вложенные цепочки. Проверяются версия Minecraft, загрузчик, объявленные
несовместимости и Fabric-манифесты внутри JAR: вложенные библиотеки, нужные версии
модов и требования к загрузчику. Файлы сначала скачиваются во временный каталог;
ошибка или отмена загрузки не меняют сборку. При ошибке применения выполняется откат.

Проверки не гарантируют, что любые моды будут работать вместе: неизвестные
конфликты во время игры и требования к произвольной Java нельзя полностью
определить при установке. Несовместимые выбранные версии отклоняются, а не
заменяются молча на старые. На CurseForge доступен пакетный выбор, но зависимости
пока не устанавливаются автоматически.

## Авторизация и настройка API

Публичный идентификатор приложения Microsoft находится в
`src/core/auth-config.js`. Окно входа использует обмен кодом авторизации с PKCE.
Client ID является публичным идентификатором; Client Secret добавлять
в настольное приложение не нужно.

Для CurseForge используйте раздел «Сервисы» в настройках или переменную
окружения `CF_API_KEY`. Для локальной разработки можно создать
`src/core/keys.local.js`: этот файл исключён из Git. Не публикуйте секретные
ключи, токены аккаунтов и пользовательские данные.

## Проверки

```sh
node test/fabric-check.js
node test/modrinth-install.js
node test/auth.js
node test/data-dir.js
node test/curseforge-key.js
node test/keys.js
```

Первые пять скриптов используют изолированные тестовые данные. Проверка переводов
сообщает об отсутствующих ключах и неверных строках словаря; динамические
префиксы ключей могут появляться в её выводе.

## Сайт

GitHub Pages публикует папку `docs/`. Домен: https://aluma.lostcat.online.
Сайт выбирает русский или английский по настройкам браузера. Выбор языка
можно изменить переключателем; он сохраняется между посещениями. Для остальных
языков используется английский. Настройка DNS описана в [docs/DEPLOYMENT.md](docs/DEPLOYMENT.md).
